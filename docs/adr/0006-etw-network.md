# 0006 进程级网络速率复用 ETW 磁盘会话

状态：已接受（2026-10-31），扩展 ADR-0004。

## 背景

issue #65 要求进程列表有“网络”列（收 + 发字节速率）。系统没有按进程的网络速率计数器，只有 ETW 事件可用，需要管理员权限。

## 决定

- **不另开会话**：在 ADR-0004 的私有内核会话（`accurate_disk_io` 开关）上多开 `EVENT_TRACE_FLAG_NETWORK_TCPIP`，网络与磁盘共用一个会话、一个回调、一把聚合器锁。用户已确认合并到同一个开关（不新增设置项）。
- **事件来源与 issue 原文的偏差**：issue 提到 `Microsoft-Windows-Kernel-Network` 清单提供者。清单提供者需要另开一个 ETW 会话（系统会话数有限、多一条回调线程与缓冲区），而内核经典 `TcpIp`（{9a280ac0-c8e0-11d1-84e2-00c04fb998a2}）与 `UdpIp`（{bf3a50c5-a9c9-4988-a7e9-b2ab8d88e4a9}）事件可以直接并入现有系统记录器会话。负载前两项是 PID 与字节数（操作码 10 发送 / 11 接收 / 26、27 为 IPv6），不需要线程表还原归属，解析比磁盘更简单。
- **口径**：TCP + UDP 的收 + 发字节数，不含 ICMP 与回环以外的协议细节；单位 Mbps（按 8 位/字节、10⁶ 换算）。应用行显示自身加全部后代的合计。
- **没有读数**：开关关闭、未提权、会话未就绪或窗口不可信（`Window::trustworthy` 失败）时 `net_rate = None`，列显示“—”，不报错。设置页的说明文字同时写明网络列依赖该开关。
- **开销**：磁盘事件每秒几百条；网络事件在高吞吐下可达每秒数万条，回调只做 GUID 比较和一次加锁累加，按进程累计表沿用 65536 项上限。需要提权后用 `measure-idle.ps1` 复测，超出 ADR-0004 的 +0.1 个百分点预算时需要改为采样或降频。
- **列头提示**：当前列头没有提示控件，未提权的原因写在设置页开关下的说明；以后加列头提示时再接。
