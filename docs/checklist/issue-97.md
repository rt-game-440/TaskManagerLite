# Issue #97 性能页左栏宽度可拖动 人工验收

- [ ] 拖动调整
  - 操作：进入性能页，鼠标移到左栏卡片列表与右侧详情之间的空隙，按住左键左右拖动。
  - 预期：光标变为左右双箭头，悬停时出现竖线、按住时变为强调色；左栏宽度随鼠标实时变化，最窄约 180px（卡片文字以省略号截断），最宽不超过 480px 且详情区至少保留约 420px；曲线、详情布局随之重排无错位。
  - 用户反馈：
- [ ] 双击恢复与持久化
  - 操作：拖到较宽后退出重启；再双击分隔条；缩小窗口到最小尺寸后再放大。
  - 预期：重启后保持上次宽度；双击恢复默认 240px；窗口变窄时左栏自动收窄，放大后回到设定宽度。
  - 用户反馈：
- [ ] 迷你模式不受影响
  - 操作：拖宽左栏后双击卡片进入迷你模式，再返回。
  - 预期：迷你窗口布局与之前一致；返回后左栏仍是设定宽度。
