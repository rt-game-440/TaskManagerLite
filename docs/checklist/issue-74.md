# Issue #74 进程详情窗口（模块页签）人工验收

自动化已覆盖：`pwsh scripts/test-process-details.ps1`（模块行数与 .NET 一致、描述读到、System 进程显示原因）。

- [ ] 进程页右键任意进程 →“详细信息…”，弹出独立窗口，标题行为“进程名（PID n）”，页签“模块”高亮，“线程”“句柄”灰色不可点
  - 预期：模块表含名称、路径、基址、大小、描述、公司；描述/公司稍后补齐，窗口不卡
  - 用户反馈：
- [ ] 窗口开着时，在目标进程里加载新 DLL（或打开 / 关闭一个有插件的程序）
  - 预期：约 1 秒内列表更新，模块数同步
  - 用户反馈：
- [ ] 右键 System（PID 4）或受保护进程 →“详细信息…”
  - 预期：整页显示原因；需要权限的显示“以管理员身份重启”按钮，点击走 UAC 重启
  - 用户反馈：
- [ ] 拖动列宽、改窗口大小后关闭，再次打开
  - 预期：大小与列宽保持；关闭后任务管理器自身 CPU 无额外占用
  - 用户反馈：
- [ ] 对 32 位进程（如 SysWOW64 下的程序）打开
  - 预期：能列出 32 位模块
