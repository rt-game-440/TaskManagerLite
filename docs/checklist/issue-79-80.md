# 验收清单：进程行变化高亮（#79）与按类型着色（#80）

自动验收：`pwsh scripts/test-row-changes.ps1`（需先 `cargo build -p tml-app --release`）。以下为需要人工目视的项目。

- [ ] 变化高亮观感：打开记事本，进程列表出现的新行显示浅绿，约 1.5 秒后恢复；关闭记事本，该行变浅红并保留约 1.5 秒后消失。
  - 预期：高亮柔和、文字清晰；深色与浅色主题都可读；选中行时仍显示选中色。
- [ ] 刚启动本程序时整张表不整体高亮。
- [ ] 设置页“进程列表”→关闭“高亮新启动和刚退出的进程”后，上述行为消失，列表与以前一致。
- [ ] 树形 / 分组视图下，退出的行保留在原位置附近，不引起选中项跳动。
- [ ] 类型色条：设置页开启“按类型显示行首色条”后，行首出现 3px 色条：关键进程红、已提权橙、系统账户紫、承载服务蓝。
  - 说明：已提权 / 系统账户依赖已读到的静态信息（显示“用户名”或“已提权”列后才有数据）；承载服务依赖服务宿主信息（开启色条时自动采集）。
- [ ] 关闭色条后行首无色条；开启时列表滚动、刷新无明显卡顿。
