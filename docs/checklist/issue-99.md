# Issue #99 设置页检查更新（一期）人工验收

- [ ] 真实网络检查更新
  - 操作：设置页 → “更新”分组 → 点“检查更新”。
  - 预期：按钮短暂显示“正在检查…”并禁用，随后显示“已是最新版本（最新正式版 x.y.z）”或“发现新版本 x.y.z”及发布说明前几行；整个过程界面不卡顿。
  - 用户反馈：
- [ ] 断网时的提示
  - 操作：断开网络（或开飞行模式）后点“检查更新”。
  - 预期：数秒内显示红色“检查失败：…”及可理解的原因（连不上服务器 / 超时），不弹窗、不崩溃；恢复网络后再点可以正常检查。
  - 用户反馈：
- [ ] 打开 Releases 页面
  - 操作：点“打开 Releases 页面”；再在“发现新版本”状态下（可用 `TML_UPDATE_URL` 指向本地模拟服务）点一次。
  - 预期：默认浏览器打开 `https://github.com/rt-game-440/TaskManagerLite/releases`（发现新版本时打开该版本的发布页）。
  - 用户反馈：
- [ ] 外观与英文
  - 操作：深浅色各看一次“更新”分组；设置语言切到 English 再看。
  - 预期：文字清晰、发布说明换行不溢出，按钮不被挤压；英文文案完整。
  - 用户反馈：
