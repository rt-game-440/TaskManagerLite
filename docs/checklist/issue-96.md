# Issue #96 进程页表头总占用 人工验收

- [ ] 与原生任务管理器对照
  - 操作：同时打开原生任务管理器“进程”页与本程序进程页（两者采样间隔都设为 1 秒）；分别在空闲、复制大文件（磁盘）、下载大文件或测速（网络）、播放视频或跑 3D 程序（GPU）时对比表头上行百分比。若已接管 Ctrl+Shift+Esc，先 `--unregister-taskmgr` 或用 `taskmgr.exe /0` 以外的方式确认打开的是原生任务管理器。
  - 预期：CPU、内存、磁盘、网络、GPU 五项数值与原生同量级、同趋势（允许采样时刻不同带来的几个百分点差）；多块磁盘时取最忙那块，而不是平均。
