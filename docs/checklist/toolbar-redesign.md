# 顶部栏重新整理（页面标题 + 本页操作，全局设置收进设置页）

离屏截图已自动核对：进程 / 性能 / 连接页在 760 与 1080 宽下顶栏不裁剪，设置页未提权 / 已提权两种状态，状态栏暂停态。以下需要人工操作体验。

- [x] 1. 各页顶栏
  - 操作：依次切到进程、性能、启动项、服务、连接、设置页；把窗口拉到最窄再拉宽。
  - 预期：左侧是大号页面标题，右侧只有本页操作（进程页：搜索、平铺/树形/分组、结束进程；性能页：迷你模式图标；启动项/服务/连接：搜索；设置页：无）。不再有刷新间隔下拉、置顶图钉和“以管理员身份重启”。窄窗口下搜索框缩短、标题不被挤掉。搜索框、分段切换、按钮、迷你模式图标按钮上下边缘齐平（统一 32px 高）。
  - 用户反馈：通过
- [x] 2. 状态栏暂停 / 继续
  - 操作：点状态栏右侧“暂停刷新”，再点“继续刷新”；在设置页把刷新间隔改成 2 秒后再试一次。
  - 预期：暂停后左侧出现“已暂停刷新”，数据停止更新，按钮变成“继续刷新”；继续后回到暂停前的间隔（2 秒那次回到 2 秒），设置页的刷新间隔同步变化。
  - 用户反馈：通过
- [x] 3. 设置页“管理员权限”
  - 操作：普通权限启动，进设置页“常规”，点“以管理员身份重启”。
  - 预期：弹 UAC，确认后以管理员身份重启；重启后这一行显示“已是管理员”。取消 UAC 时状态栏提示“已取消以管理员身份重启”。
  - 用户反馈：通过
- [x] 5. 性能页导出快照
  - 操作：性能页点顶栏右侧迷你模式左边的下载图标按钮；悬停片刻看提示；保存后用 Excel 打开。
  - 预期：悬停提示“导出当前快照…”；点击弹出保存对话框，导出内容与以前相同。左栏底部不再有通栏按钮，卡片列表一直延伸到底部。
  - 用户反馈：通过
- [x] 4. 窗口置顶
  - 操作：设置页“外观 → 窗口置顶”打开再关闭，重启确认保持。
  - 预期：与以前顶栏图钉的效果相同。
  - 用户反馈：通过
