# Issue #89 语言设置 人工验收

- [ ] 跟随系统
  - 操作：设置页语言选“跟随系统”，重启；分别在中文与英文 Windows 显示语言下启动。
  - 预期：中文系统显示中文，英文系统显示英文。
  - 用户反馈：
- [ ] 立即切换
  - 操作：设置页语言切到 English，再切回简体中文；打开迷你窗口、托盘菜单（需开启“关闭到托盘”）。
  - 预期：界面、迷你窗口、托盘菜单立即变化，无需重启；重启后保持所选语言。
  - 用户反馈：
- [ ] 旧设置升级
  - 操作：删除 settings.json 中的 `language` 字段后启动。
  - 预期：行为与旧版一致（跟随系统），退出后写回 `"language": "system"`。
