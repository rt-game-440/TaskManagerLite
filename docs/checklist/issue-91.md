# #91 进程详情窗口：句柄页签 人工验收

自动化：`pwsh scripts/test-process-details.ps1`（句柄行数对比 HandleCount、名称读取、explorer 大量句柄不卡住）。

- [ ] 进程页右键任一进程 → “详细信息…” → 切到“句柄”页签
  - 操作：观察列表与顶部“N 个句柄”
  - 预期：类型、名称、句柄值、访问掩码四列；名称在列表出现后陆续补上；窗口不卡顿
  - 用户反馈：
- [ ] 在过滤框输入 `File`、`Key`
  - 预期：只显示对应类型，顶部显示“N / M 个句柄”
  - 用户反馈：
- [ ] 对 explorer.exe 打开句柄页签，再切回“模块”页签
  - 预期：不卡死；切走后不再读取句柄（任务管理器里无残留线程）
  - 用户反馈：
- [ ] 对受保护进程 / System 打开
  - 预期：整页显示原因；未提权的拒绝访问时提示“以管理员身份重新启动”
  - 用户反馈：
- [ ] 已知限制：个别对象类型（如 `#50`）解析不出类型名，显示为 `#编号`；命名管道等会卡住的句柄显示“（无法获取名称）”
