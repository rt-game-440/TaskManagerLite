# 进程页表头分隔线拖动（只调左侧一列，右侧各列平移）

- [x] 1. 拖动基本列右侧的分隔线
  - 操作：在进程页把 PID 和 CPU 之间的分隔线向左拖，再向右拖；CPU、内存、磁盘右侧的分隔线也各试一次。
  - 预期：只有分隔线左边那一列变宽或变窄，右边各列宽度不变、跟着分隔线平移；名称列不动；分隔线始终跟着鼠标；列太窄（48px）或太宽（1200px）时停住。表格总宽小于窗口时右侧留空，大于窗口时出现横向滚动条。
  - 用户反馈：通过
- [x] 2. 名称列右侧的分隔线
  - 操作：拖动名称和 PID 之间的分隔线；再双击它。
  - 预期：拖动时名称列变宽或变窄，右侧各列平移。双击后回到默认布局（见第 6 项，和第一次打开时一样）。
  - 用户反馈：通过
- [x] 3. 显示“详细信息”列后拖动
  - 操作：表头右键勾选几个详细信息列，拖动它们右侧的分隔线。
  - 预期：规则同第 1 项；重启后列宽（包括名称列）保持。
  - 用户反馈：通过
- [x] 5. PID 列默认隐藏、GPU 列默认显示
  - 操作：用全新设置（删除或改名 `%APPDATA%\TaskManagerLite\settings.json`）启动；再在表头右键勾选/取消“PID”，重启；最后点“恢复默认列”。
  - 预期：首次启动没有 PID 列，最右有 GPU 列。PID 可以从表头右键菜单打开或关闭，重启后保持。“恢复默认列”后 PID 隐藏、只剩 GPU 一列详细列。PID 隐藏时导出 CSV 也不含 PID 列。
  - 用户反馈：通过
- [x] 6. 默认布局：CPU、内存、磁盘、GPU 等宽撑满
  - 操作：全新设置启动（或双击名称列右侧分隔线、或表头右键“恢复默认列”），再拖动窗口改变宽度。
  - 预期：名称列约 300px，CPU、内存、磁盘、GPU 四列等宽并填满其余宽度，窗口变宽变窄时四列一起变。拖动任一分隔线后布局固定（之后改窗口宽度列宽不变）。
  - 用户反馈：通过
- [x] 4. 双击 PID 等列的分隔线
  - 操作：双击任一非名称列的分隔线。
  - 预期：该列恢复默认宽度，右侧各列平移，名称列不变。
  - 用户反馈：通过
